# Salome tutvustusleht

Lihtne Salomed tutvustav veebileht, millele on lisatud foto ja kaks linki.

[Vaata veebilehte](https://salomelole.github.io/repositooriumi-nimi/)

## Lehe sisu
- Nimi ja lühike tutvustus
- Foto
- Hobid
- Lingid GitHubi profiilile ja Viljandi Kutseõppekeskusele

## Kasutatud tehnoloogiad
Leht on loodud HTML5 ja Tailwind CSS-iga. Kujundus kohandub nii arvuti kui ka telefoni ekraanile. Stiliseerimiseks kasutatakse Tailwind CSS-i CDN-i läbi võrguühenduse.

## Kohalik vaatamine
Laadi repositoorium alla ja ava `index.html` veebibrauseris. Veendu, et pildifail `image_3032dc.jpg` asub `index.html` failiga samas kaustas. Stiilide ja fontide laadimiseks on vaja internetiühendust.

## Muutmine ja avaldamine
Teksti, pildi ja kujunduse muutmiseks redigeeri faili `index.html`. Salvesta muudatused GitHubis harusse `main`.

Veebileht avaldatakse GitHub Pagesiga haru `main` juurkaustast (`/`). Muudatuste salvestamisel uuendab GitHub Pages lehte automaatselt; avaldamise edenemist näeb repositooriumi vahekaardil **Actions**.
